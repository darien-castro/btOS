*just as puppet showmen have screens in front of them at which they work their puppets*
## Introduction
btOS project using the Qt libary to create a intentional and productivity aligned cellphone OS that began due to an increasing disdain towards unintentional technologic use. As is, it is not a finished project (likely will never be), and will continue to grow and become reimagined as perspectives change (as is common in life). It is meant to serve as both a personal passion project, and a constant reminder about how we should interact with technology.
