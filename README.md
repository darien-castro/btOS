## Introduction
btOS is a "OS Wrapper" made using the Qt libary to create a intentional and productive cellphone OS. This project began due to an increasing disdain towards unintentional technological use and predatory algorithmic tendencies. btOS it is not a finished project. It is meant to serve as both a personal passion project, and a constant reminder about how we should interact with technology and push back against predatory behavior.
