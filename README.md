## Introduction
btOS is a "OS Wrapper" made using the Qt libary to create a intentional and productive cellphone OS. This projcet began due to an increasing disdain towards unintentional technologic use and predatory algorithmic tendancies. btOS it is not a finished project (likely will never be), and will continue to grow and become reimagined as perspectives change (as is common in life). It is meant to serve as both a personal passion project, and a constant reminder about how we should interact with technology and push back against predatory behavior.
